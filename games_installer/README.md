# ID6 Game Room installer: quick start

1. Park, keep iDrive awake, connect the PC to the car with an ENET cable, and enable the head unit's temporary root SSH access, for example with the Bavarian SSH Client (https://ssh.bavarian-aa.uk/, a separate tool). The access closes whenever the head unit restarts, so enable it again before each use of the installer.
2. Run the installer and press **Find car**. Enter the root SSH password. Check the SSH fingerprint before you trust it.
3. Press **Install**. When it reports every file verified, restart iDrive (hold the volume/power knob) while parked.
4. Open **My Vehicle > Game Room** with a wired Xbox controller in the car's USB port.
5. Add your own NES, Game Boy, PlayStation (plus BIOS) or PSP games under **Your games**.

Game Room is free. If you paid for it, you were sold something that is given away at https://github.com/CalgonDD/id6-game-room.

Use it only while parked. This is unofficial software, not made or approved by BMW.
